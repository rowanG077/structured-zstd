1,000 decodes per arm; raw 30,000, longrepeat 50,000. Compression and output
verification are outside the timer. No concurrent builds or tests. Changes
below about 1.5% can include code-layout effects. Broad C parity remains unfinished.

```sh
nix develop
cargo build --release -p ffi-bench --example decode_loop_z000033
taskset -c 2 target/release/examples/decode_loop_z000033 3 1000 rust
taskset -c 2 target/release/examples/decode_loop_z000033 3 1000 ffi
```

Argument four accepts an input path or `synthetic` for the raw control.
The five alphabet/mixed inputs are also generated by
`cross_ffi_compress_rust_decompress_x2_literal_shapes`.
For reproduction: generate 1 MiB with a wrapping 64-bit LCG,
`state = state * 6364136223846793005 + 1442695040888963407`.
Alphabet inputs start at `0x517cc1b727220a95` and emit `(state >> 56) % N`.
Mixed inputs start at `0x85dbcf079257`: emit `(state >> 32) % 16` when
`state >> 56` is below 243/230 for mixed95/mixed90; otherwise emit
`16 + (state >> 32) % 240`. Longrepeat repeats a 65,536-byte prefix sixteen
times, using the alphabet seed and the raw high byte.

Validation: 1,077 unit tests and six C interoperability tests pass; one unit test
is ignored. All supported CPU tiers are replayed. Pointer/copy boundary and
20,000-case Huffman oracle tests pass Valgrind. WASM, AArch64 and native no_std
compile checks pass. No Rust inline assembly remains.
